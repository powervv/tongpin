# 同频

给深圳高一用的单人学业本。按学校已经讲到的章节出英语、数学、物理、化学练习卷，登记学校试卷上的错题，并按知识点再出同类题。

预置教材：

- 数学：人教 A 版必修第一册
- 物理、化学：人教版必修第一册
- 英语：外研版（2019）必修第一册

第一次打开时，进度按 2026 年 11 月、高一上学期第 10 周左右的常见进度预置。首页会标明这只是参考，请在「进度」里改成学校实际讲到的节。未学的章节不会进卷。

## 怎么用

1. 打开首页，看四科讲到哪里、有没有盲点。不对就去进度里把章节改成未学、在学或已学。
2. 选出科目和卷型（周练、月考、期中、期末）。可以在线做，也可以先打印空白卷。答案在交卷之后才出现。
3. 交卷后看对错、错因和分步解析。点「同类题」再做同一知识点的新题。
4. 学校卷发下来后，在错题本里登记名称、日期、得分，再逐道写下错题、知识点和错因。

题目都是程序里的原创题模。数理化的答案由另一段独立验算核对；英语按外研单元写了词汇、语法和短篇阅读。不接外部模型出题。

## 本地运行

```bash
npm install
npm run dev
```

开发服务在端口 4317。没有设置 `DATABASE_URL` 时，记录写在本机的 PGlite 文件里，换浏览器仍能看到。设置了 `DATABASE_URL` 时使用 Postgres，部署构建末尾会跑 `scripts/migrate.mjs`。

```bash
npm test
npm run build
```

发布给家里人看时，请选仅自己或团队可见。这本账只有一个学生，分数都在同一个数据库里。
